# Terço-Online
Terço para acompanhar

Este site foi feito para os jovens acompanharem enquanto rezamos o terço online. Na tela aparece o terço inteiro, e a conta em que estamos fica brilhando. A oração da vez aparece escrita ao lado, então ninguém se perde, mesmo quem está começando.

Como usar:

No computador, use as setas ← → do teclado para avançar ou voltar a cada oração.
No celular, toque nos botões “Avançar” e “Voltar”.
Se perder o ponto, é só tocar na conta em que estamos para ir direto até ela.
Escolha o mistério do dia (Gozosos, Luminosos, Dolorosos ou Gloriosos) nas abas acima da oração.

Entre, acompanhe e reze conosco! 🙏
